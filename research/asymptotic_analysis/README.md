# Asymptotic Analysis README

This section is meant to explore the game beyond its physical bounds. Originally, the goal was to let the number of sides tend to infinity, but that proved difficult, and the game itself did not provide much insight into the problem. However, as described in `notes/discovery.md`, I eventually transitioned the research to an admittedly large tangent.

There are artifacts from the original research, and I've done my best to distinguish them from the newer work. This README acts as a basic summary of each directory and, where necessary, the individual files within it.

## OEIS Submission

Some of these files serve as supporting materials for an [Online Encyclopedia of Integer Sequences (OEIS) submission](https://oeis.org/draft/A399323).

## The Open Question

This research has established many properties of the polynomial family, but one question remains: what do the internal rows of the polynomial triangle represent? For more information, see the OEIS draft and the proofs provided here.

## proofs

### `integral_recursion_proof.md`

Proves the integral construction of the polynomial family from its derivative recurrence and boundary condition.

### `explicit_formula_proof.md`

Develops the explicit formula and exponential generating functions for the polynomial family, including the diagonal generating function expressed using the Lambert W function and Hermite polynomials. This is the centerpiece of the mathematical work.

### `lagrange_inversion_lemma.md`

Establishes the coefficient identity used in the generating-function proof through Lagrange inversion.

## notes

There is one file in this section, `discovery.md`. It describes the rough path that led me to investigate this particular polynomial family.

## code

### `generate_polynomial_triangle.m`

Mathematica implementation of the polynomial recurrence, generating the triangle for a chosen parameter and maximum index.

### `generate_polynomial_triangle.py`

Python/SymPy implementation that generates the polynomial triangle and exports its entries in indexed text format.

### `full_length_vector_sums_generator.py`

Old research code that enumerates the distinct full-length vector sums of two permutations of $1,\ldots,n$.

### `partial_vector_sums_generator.py`

Similar to the full-length generator, but also computes distinct partial vector sums for shorter prefixes.

### `generate_partial_vector_sum_triangle.rs`

Parallelized Rust implementation of the partial-vector-sum computation. This contains the raw Rust code, without the surrounding Rust project tooling. Dependencies are Rayon and sysinfo

## data

Contains data generated by scripts in `code`. Of particular interest is `b_file.txt`, which contains the polynomial triangle's entries through \(n=100\), flattened into a sequence of 5,050 values. This data is included in the OEIS draft as supporting table data.

## archive

Contains old research notes, handwritten scratchwork, and proof attempts. Many files contain incorrect information, incomplete ideas, or approaches that have since been abandoned. These files are preserved for historical context and should not be treated as reliable references to the current results.
