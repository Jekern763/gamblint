# How to view the interactive graph

1. Make sure you have all the proper dependencies. If you are using uv then run `uv sync`. Otherwise make sure you have flask installed for this specefic run
2. From `gamblint/research` run `uv run python interactive_graph/interactive_graph.py` or equivalent command if not using uv
3. Go to the displayed local host port, usually [127.0.0.1:5000](`http://127.0.0.1:5000`)
